# TaskManager — Kanban Board Application

[![Live Demo](https://img.shields.io/badge/demo-online-brightgreen.svg)](https://front-end-production-a5fa.up.railway.app/)

**TaskManager** — это современное полнофункциональное приложение для управления задачами в стиле Kanban-доски. Проект спроектирован с упором на производительность, безопасность и удобство использования, используя современные технологии разработки.

🚀 **Живое демо:** [https://front-end-production-a5fa.up.railway.app/](https://front-end-production-a5fa.up.railway.app/)

---

## 🛠 Технологический стек

Проект разделен на две основные части: клиентскую (Front-end) и серверную (Back-end).

### Front-end
- **React 19** & **TypeScript** — современная UI-библиотека с типизацией.
- **Vite** — сверхбыстрый сборщик проекта.
- **Zustand** — легковесное и эффективное управление состоянием.
- **TanStack Query (React Query)** — синхронизация данных с сервером, кэширование и обработка состояний загрузки.
- **Vitest** — современный фреймворк для юнит-тестирования.
- **Vanilla CSS** — чистые стили для высокой производительности и полного контроля.

### Back-end
- **Node.js** & **Express** — надежный и масштабируемый серверный движок.
- **TypeScript** — строгая типизация на стороне сервера.
- **PostgreSQL** — мощная реляционная база данных для хранения задач и пользователей.
- **JWT (JSON Web Tokens)** — безопасная аутентификация по токенам.
- **Bcryptjs** — надежное хеширование паролей.

### Infrastructure & DevOps
- **Docker & Docker Compose** — контейнеризация всего окружения (API + DB).
- **Railway** — платформа для деплоя и хостинга.

## ✨ Основные функции

- **Аутентификация:** Регистрация и вход пользователей с использованием защищенных JWT-токенов.
- **Управление задачами (CRUD):** Создание, чтение, обновление статуса и удаление задач.
- **Kanban-интерфейс:** Наглядное разделение задач по колонкам (в процессе реализации/планирования).
- **Валидация данных:** Строгая проверка вводимых данных как на клиенте, так и на сервере.
- **Защищенные роуты:** Доступ к управлению задачами только для авторизованных пользователей.

## 🧪 Тестирование

Часть функционала проекта (особенно бизнес-логика валидации) покрыта автоматическими тестами для обеспечения стабильности.

- **Инструмент:** Vitest.
- **Что тестируется:** Логика валидации названий задач (минимальная длина, максимальная длина, обработка пустых строк).
- **Запуск тестов:** `npm run test` в директории `front-end`.

## 🐳 Развертывание через Docker

Проект полностью готов к запуску в изолированных контейнерах. В `docker-compose.yml` описана конфигурация для базы данных PostgreSQL и серверной части.

### Как запустить локально:

1. Клонируйте репозиторий.
2. Убедитесь, что у вас установлен Docker и Docker Compose.
3. Запустите сборку и старт контейнеров:
   ```bash
   docker-compose up --build
   ```
4. API будет доступно на порту `5000`, а PostgreSQL на порту `5433`.
